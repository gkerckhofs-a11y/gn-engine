# Vues d'ambiance — lieux de Breach Port

Les cinq images ont été fournies par le créateur de Space Outlaws, le 17 novembre 2026.
Elles reconstituent les bâtiments réels servant de terrain de jeu à Western City, dans une ambiance nocturne de science-fiction. Elles sont utilisées comme **illustrations d'ambiance**, jamais comme photographies documentaires ni comme cartes de navigation.

Les sources originales sont archivées dans le dossier Drive « Space Outlaws – Holopédia – lieux de Breach Port » et partagées en lecture seule avec `gn-engine-deployer@gn-engine.iam.gserviceaccount.com`. Elles sont référencées par `assets-source/place-images.json`. Le script `assets-source/download-planets.py` les transforme en WebP 1600×900 avant le déploiement exclusivement sur `hosting:holopedia`.

Les articles et les secrets de GN Engine ne sont pas modifiés. Les sept fiches sont servies à partir de cinq images distinctes : le bureau du préfet partage sa vue avec les docks, et l'Hospice partage sa vue avec l'Atelier. Chaque vignette adopte le cadrage de son lieu. Les originaux, et les textes des notices, restent inchangés.
