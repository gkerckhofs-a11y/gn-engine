**Statut source** reproduit le marquage de la section du V2 ; `[V/P]` reste mixte et ne vaut pas validation de tous ses détails. Les instructions explicites de reprise valident les six modules, la sécurité privée, la réutilisation et la réparation obligatoire. Les choix de barème `[A]` restent ouverts. « Existant » décrit le code dans ce périmètre, pas une recette humaine ni une garantie de conformité générale.

Les suites référencées sont des points de preuve réutilisables : elles ne prouvent pas une fonction absente. Les tests nouveaux `master-workspace` couvrent L1a ; résultats d’exécution dans le rapport de validation. Aucun scénario REC n’a été exécuté manuellement pour ces tranches. Les tests partagés [master-editors](../test/support/master-editors-suite.mjs) et les tests [interface](../test/master-editors-ui.test.mjs) couvrent L1b ; leur résultat est distingué de la recette humaine. L1c ajoute la suite partagée [master-catalog-editors](../test/support/master-catalog-editors-suite.mjs) et trois tests de rendu/contrôleur.
